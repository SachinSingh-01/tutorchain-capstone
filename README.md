# TutorChain — Capstone Project (Demo Mode)

## 📌 Overview
TutorChain ek multi-agent educational assistant hai jo students ko personalized tutoring provide karta hai.

Is project me:
- Lesson Plan Generator (Planner Agent)
- Tutor Agent (explanation + exercise)
- Assessor Agent (grading + feedback)
- Persistent Memory (student progress)
- Tools: Code Execution + Search Tool
- LLM Wrapper (Local mode abhi, Gemini baad me)

Yeh project abhi demo mode me hai (local LLM). Baad me Gemini connect karenge.
